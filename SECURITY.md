# Sécurité

Ne publiez jamais d’identifiant Picnic, de code de connexion, de jeton, de cookie ou de donnée personnelle dans une issue publique.

Pour signaler une vulnérabilité, utilisez de préférence un signalement privé dans l’onglet **Security** du dépôt GitHub. Si cette option n’est pas disponible, passez par la page [Support AgentVegan](https://agentvegan.org/support) sans inclure de secret dans le premier message.

Indiquez la version de ChatGPT Desktop, le système utilisé, le résultat observé et les étapes minimales permettant de reproduire le problème.

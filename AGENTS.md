# AgentVegan Plugin

Ce dépôt public distribue uniquement le plugin AgentVegan pour ChatGPT Desktop.

- Conserver le MCP distant `https://mcp.agentvegan.org/mcp` comme unique connexion d’exécution.
- Ne jamais ajouter de session marchand, identifiant, jeton, cookie, profil utilisateur, secret d’infrastructure ou donnée privée de la plateforme.
- Maintenir la mention explicite « ChatGPT Desktop uniquement » tant que l’installation GitHub n’est pas réellement prise en charge sur le Web et sur mobile.
- Ne jamais présenter une commande, un paiement ou une modification de panier comme automatique sans confirmation explicite de l’utilisateur.
- Garder tous les textes destinés aux utilisateurs en français naturel.
- Valider le plugin et le manifeste du catalogue avant chaque publication.

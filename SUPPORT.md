# Assistance

Avant de demander de l’aide :

1. vérifiez que vous utilisez l’application ChatGPT Desktop et non le site Web ou l’application mobile ;
2. fermez complètement puis relancez ChatGPT ;
3. vérifiez que le plugin AgentVegan apparaît dans Codex ;
4. réessayez avec une demande simple, par exemple `Trouve-moi une recette végane avec du tofu.`

Si le problème persiste, ouvrez une issue GitHub en indiquant votre système, votre version de ChatGPT Desktop et le message d’erreur exact. N’y joignez jamais d’identifiant, de code Picnic, de jeton, de cookie ou de donnée personnelle.

La page d’assistance générale est disponible sur [agentvegan.org/support](https://agentvegan.org/support).
